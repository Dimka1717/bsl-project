# EME: маркировка (как передавать и как получать)

## Где в коде находится логика по маркам

### 1) Базовые функции формата кода марки
- `EmeWmsУтилиты.КодМаркиВЗначениеБезСкобок()` — приводит код к виду без скобок AI `(01)(21)`.
- `EmeWmsУтилиты.КодМаркиВЗначениеСоСкобками()` — сейчас фактически возвращает вход как есть (историческая логика со скобками отключена).
- `EmeWmsУтилиты.ПолучитьВыборкуКодовМаркировки()` — выборка всех кодов маркированного товара из справочника штрихкодов упаковок.
- `EmeWmsУтилиты.ПолучитьМаркиЧЗТоваров()` — формирует CSV-выгрузку, где марка уходит в поле `true_sign` в Base64.

### 2) Универсальный прием марок из входящего сообщения WMS
- `EmeWmsДрайвер.ПолучитьТаблицуМарокИзСтрокSSCC()`:
  - читает дочерние строки `sscc`;
  - берет `ERPData.sscc.true_sign`;
  - сопоставляет товар/серию/характеристику;
  - кладет строки в `ТаблицаМарок`.
- `EmeWmsДрайвер.ДобавитьМаркиВТЧШтрихкодыУпаковок()`:
  - находит/создает штрихкод упаковки;
  - добавляет ссылки в ТЧ документа `ШтрихкодыУпаковок`.

### 3) Прикладные импортные модули (дублируют паттерн)
В документах импорта (`Реализаций`, `Списаний`, `Корректировок`, `Перемещений`) используется один и тот же шаблон:
- из `sscc.true_sign` собирается таблица марок;
- затем марки добавляются в ТЧ `ШтрихкодыУпаковок` документа.

## Как ПЕРЕДАВАТЬ марки (ERP -> WMS)

В проекте есть два рабочих канала:

1. **CSV-канал через `ПолучитьМаркиЧЗТоваров()`**
   - источник марок: справочник `ШтрихкодыУпаковокТоваров` с типом упаковки `МаркированныйТовар`;
   - преобразование: `КодМаркиВЗначениеБезСкобок()`;
   - перед отправкой код кодируется в Base64;
   - целевое поле: `true_sign` в строке CSV.

2. **Сообщение с дочерней таблицей `sscc`**
   - для совместимости с приемом в ERP нужно передавать `true_sign` в каждой строке `sscc`;
   - также обычно передаются `goods_id`, `lot_no`, `quantity`, при необходимости `box_sscc`, `pallet_sscc`.

Минимальная строка `sscc` (логический пример):

```text
goods_id=<UUID товара>;lot_no=<партия/серия>;quantity=1;true_sign=<код марки>
```

Если у вас канал ожидает Base64 (как в CSV-функции), передавайте Base64-строку в `true_sign`.
Если канал ожидает plain-текст, передавайте без Base64 в виде `01...21...`.

## Как ПОЛУЧАТЬ марки (WMS -> ERP)

Рекомендуемый путь (унифицированный):

1. В обработчике входящего документа вызвать `ПолучитьТаблицуМарокИзСтрокSSCC(Параметры)`.
2. Из `Параметры.ТаблицаМарок` добавить марки в документ вызовом `ДобавитьМаркиВТЧШтрихкодыУпаковок(...)`.
3. Записать документ.

Псевдокод:

```bsl
ПараметрыМарок = Новый Структура("ERPData", ERPData);
EmeWmsДрайвер.ПолучитьТаблицуМарокИзСтрокSSCC(ПараметрыМарок);

Если ЗначениеЗаполнено(ПараметрыМарок.ТаблицаМарок)
   И ПараметрыМарок.ТаблицаМарок.Количество() > 0 Тогда
    EmeWmsДрайвер.ДобавитьМаркиВТЧШтрихкодыУпаковок(Документ.ШтрихкодыУпаковок, ПараметрыМарок.ТаблицаМарок);
КонецЕсли;
```

## Важный нюанс по формату (почему часто «не приезжает»)

В коде есть расхождение форматов:
- для CSV-функции марка кладется в `true_sign` как **Base64**;
- в приемнике `ПолучитьТаблицуМарокИзСтрокSSCC()` берется `true_sign` как обычная строка и сразу преобразуется `КодМаркиВЗначениеСоСкобками()`, которая сейчас возвращает как есть.

То есть сторонам интеграции нужно явно договориться:
- либо `true_sign` = plain строка марки;
- либо `true_sign` = Base64 и тогда добавить декодирование на приемной стороне перед записью в `ЗначениеШтрихкода`.

## Практически для «Контур.Маркировка» (рекомендуемая схема)

Чтобы не ловить ошибки формата, для контура маркировки лучше зафиксировать один стандарт:

1. **WMS -> ERP (прием):**
   - в `sscc.true_sign` передавать **plain** код марки (без Base64), например `010...21...`;
   - ERP забирает его из `ERPData.sscc.true_sign` и пишет в `ШтрихкодыУпаковок`.

2. **ERP -> внешний контур/шина:**
   - если шина/Контур требует бинарно-безопасный формат, кодировать марку в Base64 на этапе выгрузки;
   - если шина принимает текст, отправлять plain без дополнительной кодировки.

Пример преобразования для отправки в Base64:

```bsl
ЗначениеМарки = EmeWmsУтилиты.КодМаркиВЗначениеБезСкобок(СтрокаШК);
TrueSignBase64 = Base64Строка(ПолучитьДвоичныеДанныеИзСтроки(ЗначениеМарки));
```

Пример обратного преобразования на приеме (если все же пришел Base64):

```bsl
Попытка
    КодМарки = ПолучитьСтрокуИзДвоичныхДанных(Base64Значение(ERPData.sscc.true_sign));
Исключение
    // Значит пришел plain
    КодМарки = ERPData.sscc.true_sign;
КонецПопытки;
```

> В текущем коде автоматического Base64-декодирования в универсальном приемнике марок нет,
> поэтому для Контур-интеграции важно заранее согласовать формат `true_sign`.
